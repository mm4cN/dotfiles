# Review Severity

## Critical

Likely data loss, severe security issue, destructive behavior, or system-wide failure under realistic conditions.

## High

Incorrect behavior in a core path, broad regression, crash, corruption, or serious compatibility break.

## Medium

Real defect with narrower scope, important edge case, resource leak, incorrect failure handling, or missing validation with a plausible impact.

## Low

Minor defect or maintainability issue with a concrete but limited consequence.

Do not assign severity based on code ugliness. Severity reflects user or system impact.
